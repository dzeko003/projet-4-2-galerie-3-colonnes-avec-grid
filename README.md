# PROJET 4.2 — Galerie 3 colonnes avec CSS Grid

## Description

Ce projet a été réalisé dans le cadre de la formation **Akieni Academy**.

**Semaine 4 — CSS Flexbox & Grid**

L'objectif est de concevoir une galerie d'images responsive avec **CSS Grid** en mettant une image principale en avant.

La galerie présente plusieurs lieux emblématiques, événements et paysages de Brazzaville et de la République du Congo.

## Objectifs

- Maîtriser CSS Grid.
- Créer une galerie responsive.
- Utiliser les propriétés `grid-column` et `grid-row`.
- Concevoir une interface moderne avec des effets au survol.

## Fonctionnalités

- Galerie en 3 colonnes sur ordinateur.
- Image principale occupant 2 colonnes et 2 lignes.
- Overlay affichant le titre et la description.
- Responsive :
  - 1 colonne sur mobile.
  - 2 colonnes sur tablette.
  - 3 colonnes sur ordinateur.

## Technologies utilisées

- HTML5
- CSS3
- CSS Grid
- JavaScript
